## 📊 Projects

### 1. ScholarZPath — AI-Based Scholarship Search Platform

A scholarship search platform designed to match user profiles with relevant scholarship opportunities.

**Tools:** React, TypeScript, Firebase, Groq AI, Tailwind CSS

**Key Features:**
- Scholarship search, filtering, and recommendation based on user criteria
- Preparation timeline and deadline tracking
- Firebase integration for authentication and data management
- Groq AI integration to support AI-powered features

---

### 2. COVID-19 Indonesia Analytics Dashboard

An interactive Power BI dashboard for monitoring and analyzing COVID-19 developments in Indonesia.

**Tools:** Microsoft Power BI, Data Analysis, Data Visualization

**Key Features:**
- Data preparation and processing for analysis and visualization
- New cases trend analysis
- Comparison of new cases and recoveries
- COVID-19 case distribution by province
- Trend analysis over time through multiple dashboard pages

---

### 3. Security Risk Management Audit System

A web-based cybersecurity risk management and audit platform based on the NIST Cybersecurity Framework (NIST CSF).

**Tools:** NIST CSF, Web-Based Application

**Key Features:**
- Asset Inventory
- Vulnerability Assessment
- Risk Assessment
- Audit Checklist
- Compliance Score
- Findings and Reports
- Role-Based Access Control (RBAC)
- Automated Risk Score and Compliance Score
- AI Assistant for risk mitigation recommendations
